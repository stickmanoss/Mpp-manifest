# Manifest.cpp

Manifest.cpp is a cpp file designed to run M++ without you having to download the entire project

to run make sure you have C++23 and run:

```sh
mpp manifest.cpp
```

and then:

```sh
mpp filename.mpp
```

replace filename with the name of your file


if it is inside a folder inside the folder you are in, prefix it with a foldername/ (replace foldername with the name of your folder)
